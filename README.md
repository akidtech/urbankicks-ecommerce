# UrbanKicks

UrbanKicks is a Flutter-based mobile shopping application for sneaker products.

## Features
- User Login & Register
- Product Listing
- User Management
- MockAPI Integration
- CRUD Data

## Tech Stack
- Flutter
- Dart
- MockAPI
- HTTP Package
- Shared Preferences

## Installation

```bash
flutter pub get
flutter run
```
